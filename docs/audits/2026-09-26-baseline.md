## SECURITY

1. **High: PIN failure counter rollback.** Six wrong-PIN calls through create_guardian_unlock_session left failed_attempts=0 and no lockout in a synthetic authenticated fixture. The called verifier increments counters, but the outer exception rolls them back. Fix the failure transaction contract and test persistence, cooldown, token binding and concurrent attempts.
2. **High: guardian decision and book-completion privilege gaps.** Invoker approval/return RPCs call guardian_unlock_session_valid without authenticated EXECUTE. Book Adventure completion calls award_xp_event/evaluate_child_badges with the same mismatch. Guardian helper denial was reproduced; book completion impact follows from deployed call graph/ACLs, not a full ready-book journey.
3. **Medium: admin launch gate is broken.** The full public admin_get_production_launch_gate call returns SQLSTATE 42501 because its private base helper is not executable by authenticated. The UI fails closed to "unverified."
4. **Recovery gap:** missing migration/bootstrap and Edge sources prevent claiming reproducible deployment.
5. **Auth warning:** [leaked-password protection is disabled](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection).
6. **Hardening backlog:** broad legacy table grants remain; narrow them with compatibility tests. Do not grant unguarded XP helpers to solve the execution defects.

No cross-household disclosure was observed in the tested RLS scenarios. This is not a claim of complete security coverage. No exposed secret/service-role token was found in the tracked-file pattern scan.
